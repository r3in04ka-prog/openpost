## OpenPost для Windows

Почтовый клиент с тремя колонками, тёмным интерфейсом, розовыми акцентами и светлой областью чтения.

**Что можно делать:** читать текстовые письма из входящих, искать среди загруженных сообщений, отмечать важные, писать и отвечать. Деморежим позволяет посмотреть интерфейс без подключения почты.

## Какой файл скачать

**`OpenPost-Setup-0.2.2-windows-x64.exe`** — установщик для Windows x64. Python уже включён. Установка выполняется для текущего пользователя.

- `SHA256SUMS.txt` — контрольная сумма установщика.
- `openpost-preview.png` — снимок интерфейса.
- Source code — исходники для разработчиков; это не установщик.

## Первый запуск

1. Установите и откройте OpenPost.
2. Нажмите **«Демо»**, чтобы посмотреть вымышленный ящик. Отправка в деморежиме отключена.
3. Для своей почты нажмите **«Подключить почту»**: email, пароль приложения, адреса IMAP/SMTP вашего провайдера.

IMAP: TLS, порт 993. SMTP: TLS на 465 либо обязательный STARTTLS на 587. Провайдер должен разрешать такой способ подключения.

## Ограничения и обновление

Поддерживается один аккаунт. Вложения, OAuth, другие папки, несколько аккаунтов и офлайн-хранилище ещё не реализованы. Пароль после перезапуска вводится заново. Установщик не подписан цифровой подписью.

Для обновления закройте OpenPost и запустите новый установщик. Если SMTP сообщил об ошибке после отправки, сначала проверьте доставку на сервере, прежде чем отправлять повторно.

Описание релиза уточнено 16 ноября 2026; бинарный файл версии 0.2.2 не заменялся.
