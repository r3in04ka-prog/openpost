# План развития OpenPost

Пункты ниже — направления обсуждения без обещанных сроков. [Предложить идею или сообщить об ошибке →](https://github.com/r3in04ka-prog/openpost/issues/new/choose)

## Уже работает

- [x] IMAP-входящие, чтение текстовых писем, поиск по загруженным сообщениям.
- [x] SMTP-отправка и ответы; один аккаунт за раз.
- [x] Демонстрационный ящик без подключения аккаунта и отправки.
- [x] Локальные важные письма, фильтры и установщик Windows x64.
- [x] Формы обратной связи и руководство для участников.

## Ближайшие направления

- [ ] Улучшить ошибки подключения и подсказки по IMAP/SMTP у разных провайдеров.
- [ ] Английский интерфейс и проверка клавиатурной навигации.
- [ ] Проверить расположение элементов при разных масштабах Windows.
- [ ] Уточнить состояние отправки, если сервер принял письмо до разрыва соединения.

## На обсуждение

- [ ] OAuth для провайдеров, которым недостаточно пароля приложения.
- [ ] Вложения с понятными ограничениями размера и явным выбором файлов.
- [ ] Дополнительные папки, несколько аккаунтов и управление ими.
- [ ] Опциональное локальное хранилище с отдельно описанной моделью приватности.
- [ ] Подписанный установщик.

## Первое небольшое изменение

Подойдут проверка инструкции с вымышленными данными, улучшение подсказки по подключению или исправление клавиатурного фокуса. Сначала опишите проблему в issue и прочитайте [CONTRIBUTING.md](CONTRIBUTING.md). Не используйте настоящие письма и пароли в тестах.
